## Interpretation guide

- If best_loss_step is usually the final step, the attack is still improving at the end of the 10 inner steps.
- If chosen and final distances are nearly identical, the chosen perturbation is usually the final perturbation.
- If chosen_frac_nearest_changed is close to 0 and original rank is close to 1, perturbations remain in the original token's local nearest-neighbour cell.
- If L2 to original increases but distance to nearest stays stable, the perturbation moves inside a local cell without changing nearest token.
- If top-1 to top-5 distances are very close, the perturbed point lies in a dense/ambiguous part of embedding space.
- If top-1 is much smaller than top-2, the perturbed point has a clear nearest vocabulary embedding.
